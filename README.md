# TaskFlow - Smart Task Manager

## Project Overview

TaskFlow is a simple and responsive task management web application
created using HTML5, CSS3 and JavaScript.

The project demonstrates fundamental frontend development concepts
including semantic HTML, responsive design, CSS Grid, Flexbox,
mobile-first development and basic JavaScript DOM manipulation.

---

## Features

- Responsive navigation menu
- Mobile-first responsive design
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Task progress percentage
- Responsive layout for mobile, tablet and desktop
- Accessible form labels and navigation
- Semantic HTML5 structure

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Responsive Media Queries
